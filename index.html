Developer journey

Full-stack, with AI built in

I design the product and I write the code behind it. My path runs from computer engineering to full-stack apps, then LLM products, agentic AI and small language models.

Engineering roots

B.E. in Computer Engineering from Anna University, Chennai. Design and code have been part of the same toolbox from the start.

Full-stack shipping

React and Next.js front ends, Node.js and Python back ends, SQL, Docker and Azure. EduPulse is a Next.js 14 platform with four role-based workspaces.

LLMs in real products

SheetMind AI puts a language model inside Excel. ChatCart Pro adds an AI chatbot and WhatsApp Cloud API ordering for businesses.

Agentic AI

Voice and chat agents that do work, not just answer: taking orders, syncing stock with a POS and handing off to people. VoicePilot extends this to Tamil, Malayalam and Hindi.

Small models, right-sized

Choosing an SLM when a smaller, cheaper or more private model is enough, and a larger LLM when the task needs it.
